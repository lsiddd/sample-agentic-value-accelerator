## What This Does

This use case helps support teams quickly review and respond to fictional customer support requests. It reads a support ticket, classifies it into a category, determines how urgent the issue is, and drafts a professional response. The goal is to show how an automated system can assist with triage work, giving operators a starting point for their reply while still requiring human review before anything is sent.

## How To Use It

Enter a ticket identifier in the `ticket_id` field. Choose a triage mode from the dropdown:

- `full` — Classify the ticket and draft a response
- `classify_only` — Just classify the ticket without drafting
- `draft_only` — Just draft a response without classification

The system will return the ticket's category, urgency level, and a suggested response. For categories, you can select from technical_issue, billing_inquiry, feature_request, complaint, general_question, account_access, product_info, or other. For urgency, choose low, medium, high, or urgent based on how quickly the customer needs help. An analyst reviews and approves/overrides every recommendation — the agent never finalizes.
